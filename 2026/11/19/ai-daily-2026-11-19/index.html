【AI 日报】Anthropic IPO定价83美元超区间，史上最大发行今日挂牌

2026年11月19日
#AI #人工智能 #日报

🔦 今日速览

Anthropic IPO以83美元敲定发行价、突破70-78美元区间，盘中私募合计规模上看900亿美元、估值约1.5万亿美元，今日以"ANT"挂牌纳斯达克。同一天：英伟达证实停止H200对华出货，特朗普抵达深圳、今日与习近平举行年内第三次会晤并首次召开美中俄三方峰会。补录两条隔夜重磅：OpenAI发布GPT-6.2 Astra/Sol、微软Ignite连发七款MAI模型。

趋势1：AI资本市场定价锚今夜揭晓 趋势2：芯片管制与元首会晤同频共振 趋势3：模型价格战打到前沿层

🌍 国际动态

1. Anthropic IPO定价83美元突破区间，史上最大股票发行今晚纳斯达克挂牌

事件简述：美东11月18日晚间（北京19日凌晨），Anthropic IPO最终定价83美元/股，突破此前70-78美元发行区间，也高于华尔街日报早间"80美元以上"的预测。按83美元计算，公开发行8.25亿股募资约685亿美元，叠加谷歌、英伟达、微软、AMD、博通、美光、台积电七家基石的260亿美元同步私募与绿鞋期权，本次发行总规模上看1000亿美元，超越SpaceX今年6月创下的857亿美元纪录，成为史上最大股票发行；对应估值约1.5万亿美元。认购订单达可供配售股数的近7倍（部分机构口径称10-20倍），散户配售比例高达约20%。股票今日（美东周四）以代码"ANT"登陆纳斯达克，盘前二级市场合约一度报出96美元，多家机构上市前即给出最高105美元的"买入"评级。 关键数据：定价83美元（超区间上限6.4%）｜总规模1000亿美元｜估值1.5万亿｜超额认购近7倍 影响分析：在纳指回调、英伟达治理风波与美联储加息预期（12月概率96.8%）的逆风里，Anthropic仍完成史上最大发行——公开市场首次给纯AI模型公司定价，今夜ANT的首秀将直接决定OpenAI明年上市的路径与整个AI板块的估值锚。 📅11月18日晚（美东）定价，11月19日（美东）挂牌

2. 英伟达证实停止H200对华出货：Q3对华销售24亿美元，Q4指引直接归零

事件简述：临时CEO克雷斯11月17日（美东）在财报电话会上证实，公司已停止向中国出货获出口许可的Hopper数据中心产品（含H200），未来业绩指引不再计入相关收入——截至10月25日的Q3，这部分对华销售额达24亿美元。该供货通道本由黄仁勋与特朗普政府协商敲定（芯片经美国转运、美方抽25%关税），在黄仁勋辞职与BIS 11月16日远程算力新规后正式关闭。英伟达同日宣布设立董事会层级的国家安全与出口管制委员会。11月18日中国外交部回应称"中方已多次阐明原则立场"。杰富瑞测算，远程算力新规或使英伟达明年数据中心营收减少440亿-620亿美元。 关键数据：Q3对华24亿美元归零｜杰富瑞测算新规冲击440-620亿/年｜新设董事会国安委员会 影响分析：黄仁勋在任时力保的中国市场通道，在其辞职一周后被临时管理层亲手关闭——对华收入归零叠加SEC调查与国会闭门问询，英伟达"后黄仁勋时代"的第一份财报胜利，正被地缘政治快速消耗。 📅11月17日（美东财报电话会证实），11月18日外交部回应

3. 特朗普抵达深圳，今日与习近平年内第三次会晤，美中俄三方峰会首次举行

事件简述：11月18日下午，特朗普抵达深圳宝安机场出席APEC领导人会议周，习近平前往机场迎接——这是习近平就任国家主席以来首次赴机场迎接外国领导人；普京同日抵达。今日（11月19日）APEC领导人非正式会议召开，特朗普将与习近平举行年内第三次双边会晤（5月北京、9月华盛顿之后），并在会晤后与习近平、普京举行首次美中俄三方峰会，议题聚焦核军控与"超级智能"风险管控。白宫将双边会晤定位为"检视既有承诺落实"而非新协议；双方在稀土、关税与11月16日BIS远程算力新规上仍有尖锐分歧，中方已警告可能反制。黄仁勋今年首次不出现在总统随行名单中。 关键数据：年内第三次元首会晤｜首次美中俄三方峰会｜AI风险沟通机制尚未运作 影响分析：芯片管制收紧与元首会晤同周到来，"AI超级智能安全对话"成为科技战时代第一个可能被写进双边议程的技术议题——深圳会谈成果将直接反馈到Anthropic挂牌日的市场情绪上。 📅11月18日抵达，11月19日峰会

4.【补录】OpenAI发布GPT-6.2 Astra与Sol：前沿模型打"成本战"，任务成本仅为Claude Fable 5.2的5%

事件简述：OpenAI于美东11月17日（北京18日凌晨）发布双子星模型：旗舰GPT-6.2 Astra面向复杂专业工作，日常工作版Sol主打效率。官方数据显示Astra在Agents' Last Exam上比GPT-6 Astra高5.2分、成本不到三分之一；比Claude Fable 5.2高5.5分，单任务成本仅2.89美元 vs 60.05美元（约5%，统计口径含脚注）；法律评测Harvey LAB-AA通过率超Fable 5.2两倍。API降价20%：Astra输入8美元/百万token、输出40美元；Sol沿用上一代低价（2/10美元）。已在ChatGPT Work、Codex与API全量开放。早期用户差评"手感不佳"，奥特曼回应称将优先优化可用性。 关键数据：单任务成本Fable 5.2的5%｜API降价20%｜ALE得分78.3%新高 影响分析：前沿模型竞争正式进入"每美元买多少智能"阶段——微软MAI与OpenAI在同一天用同一套性价比话术互轰，闭源双雄的价格战正在挤压所有中间层模型的生存空间。 📅11月17日发布（美东），昨日窗口内漏报，今日补录

5.【补录】微软Ignite 2026连发七款MAI模型：MAI Code 2以5%成本达Claude Opus 5.5九成六性能

事件简述：微软AI部门11月17日在旧金山Ignite 2026一次性发布七款自研模型：编程模型MAI Code 2达GPT-6.1 Sol约98%性能、40%成本，达Claude Opus 5.5约96%性能、5%成本，已上线GitHub Copilot；安全模型MAI Cyber 2 Flash在CyberGym-E2E以92.3%略胜GPT-6 Astra（91.5%）、单任务成本不到后者2%；MAI Image 2.7登顶Artificial Analysis图像编辑榜。硬件端，第二代自研加速器Maia 200已投产（每瓦token吞吐提升1.7倍），下一代Maia 300宣称每瓦token数超领先GPU 40%；MAI Licensed Weights允许企业在自有Azure环境定制模型（AT&T案例以1/50成本跑赢GPT-6.1 Sol）。苏莱曼透露自研前沿通用模型预训练"已达业界顶尖"。 关键数据：7款模型｜Opus 5.5的96%性能/5%成本｜Maia 300宣称+40%能效 影响分析：微软同时握着"OpenAI渠道"与"自研替代"两张牌——用自研模型+自研芯片把价格打到对手的5%-40%，既是给Anthropic上市夜的直接回应，也是在为OpenAI合同到期后的议价权布局。 📅11月17日（美东Ignite大会），昨日窗口内漏报，今日补录

🇨🇳 国内动态

1. 腾讯Q3财报：营收2073亿增8%，AI资本开支814亿再创新高，马化腾称"不拥抱就是生死存亡"

事件简述：腾讯11月18日发布2026年三季度财报：收入约2073亿元、同比增8%，但非国际财务报告准则下经营利润约680.73亿元、同比减少6%——此前一、二季度该项均为同比增长9%，利润端首次转负。代价来自AI投入：单季资本开支约814亿元，较去年三季度的约130亿元暴增逾5倍，创历史新高、超过上季度（528亿元）五成以上。马化腾近日在全体员工线上对话中直言："现在进行的智能革命如果不投入拥抱，就是被颠覆，这是一个生死存亡的问题。"旗下AI产品WorkBuddy登顶国内AI用量第一。 关键数据：营收2073亿(+8%)｜经营利润-6%（连续两季+9%后转负）｜资本开支814亿（去年同期130亿） 影响分析：腾讯成为"AI利润换增长"叙事的中国样本——用利润表换算力表，市场对其估值逻辑正从广告游戏现金流切换为AI基础设施投入产出比，接下来的问题是814亿/季何时兑换成收入曲线拐头。 📅11月18日发布财报

2. 2026算力互联网大会武汉开幕：中国智能算力2592 EFLOPS、同比增146%

事件简述：11月18日，2026算力互联网大会在武汉开幕。工信部信息通信科技委常务副主任韩夏披露：截至今年9月底，中国智能算力规模达2592 EFLOPS、同比增长146%、稳居世界第二；国家算力互联网服务平台已分配算力标识1198万条、汇聚资源36.2 EFLOPS；已建成70多条连接算力枢纽节点的算力传输通道。会上，国家算力互联互通（湖北）节点正式启动。 关键数据：智能算力2592 EFLOPS(+146%)｜算力标识1198万条｜70+条算力传输通道 影响分析：在英伟达H200对华通道关闭、远程算力新规封堵第三国借道的同一天，官方亮出算力增速底牌——"全国一张网"的算网调度被定位为对冲单点供给受限的国家级答案。 📅11月18日（武汉开幕）

3. OpenRouter数据：中国大模型周调用119.1万亿词元，全球前四全部来自中国

事件简述：OpenRouter最新周度数据（11月9日-15日）显示，上榜中国大模型周调用量达119.1万亿词元、环比增2.51%；同期美国大模型周调用量为14.83万亿词元，中国约为美国的8倍。全球周调用量排名前四的模型均来自中国。DeepSeek、腾讯混元、智谱GLM、通义千问持续迭代，Qwen与GLM系列开源权重持续释出，评论指出"中国已成为全球开源大模型供给最活跃的国家之一"。 关键数据：中国周调用119.1万亿词元 vs 美国14.83万亿｜全球前四均为中国模型 影响分析：调用量口径虽偏API路由平台、不完全等同总用量，但"全球前四全在中国"叠加本周百度Token收入+1159%——词元经济的量级优势正从榜单走进财报；能否转化为定价权与利润，是"价值题"的真正考点。 📅11月19日刊发（数据窗口11月9日-15日，光明日报评论引用OpenRouter）

📄 今日论文

1. 跑分更高的编程模型，并没有干完更多活

作者/机构：Yining Hua 核心贡献：首次用"自然实验"检验编程基准分数的真实含金量：6月12日美国出口管制令导致Claude Fable 5被停19天，用户被迫切换到SWE-Bench Pro上低11分的Opus 4.8——人和项目不变、只换模型。结果：分数更低的模型完成的工作量并未显著减少，基准分数与真实产出之间的相关性远弱于厂商宣传。 为什么重要：在GPT-6.2与MAI Code 2们用0.5分、1个百分点互相宣战的同一天，这篇论文给"跑分军备竞赛"泼了冷水——企业选型应看真实任务完成率，而不是榜单小数点。 📄 arXiv:2611.23216 📅11月17日

2. ATI：跨组织自主Agent的联邦身份与信任基础设施

作者/机构：Viet K. Nguyen, Mohammad I. Husain 核心贡献：针对"Agent跨企业调用工具与互访"缺乏身份、执行完整性与授权验证的问题，提出框架无关的Agent Trust Infrastructure：以PKI+零信任架构+远程认证为底座，通过组织间对等证书建立联邦信任，为每次Agent执行提供可验证的attestation与问责链。 为什么重要：微软Ignite同日推出"AI透明度计划"、Copilot升级为5000万Agent的调度器——当Agent真的跨组织干活，身份认证就是下一个MCP级协议缺口；这篇给出了工程化的信任层蓝图。 📄 arXiv:2611.23202 📅11月17日

3. RSI-Prime：让大模型学会"训练模型"

作者/机构：Dewu Zheng, Yang Ye, Hongyu Zhang 等 核心贡献：面向递归自我改进（RSI）的第一步——"模型当训练员"：构建含350条完整实验轨迹、覆盖7类任务的RSI-Prime数据集，对LLM做细粒度实验决策监督，系统性训练模型自主设计训练配置、调参并改进目标模型的能力。 为什么重要：AutoML的终局是LLM自己训模型；当各实验室都在冲"研发自动化指数"，"会训练模型的能力"正在成为可量化、可训练的显式技能——也是RSI安全讨论必须前置的能力测量点。 📄 arXiv:2611.23138 📅11月17日

4. SceneSafetyBench：VLM的"场景状态"安全漏洞

作者/机构：Tongxi Wu, Yuyang Cheng, Jiacheng Xian 等 核心贡献：识别出视觉语言模型的scene-state安全漏洞：不给明确恶意请求、仅让模型解读"事件进展中的画面"（如事故/制作过程的中间态），即可诱发有害协助。375组图文基准在8个VLM上测得45.6%-72.3%攻击成功率。 为什么重要：多模态Agent正被部署进巡检、驾驶与客服等真实场景，"看图说话"本身就是攻击面——VLM安全评估必须从静态图文对齐走向动态场景推演。 📄 arXiv:2611.23206 📅11月17日

💡 值得关注

今夜两个定价锚：ANT挂牌（盘前合约96美元 vs 发行83美元）与深圳会谈成果将同时揭晓——前者决定"AI泡沫论"与"AI需求真实论"谁能引用数据，后者决定芯片管制是继续加码还是出现AI安全对话的第一个制度化缺口。孙正义今日在东京承认"错过Anthropic是我犯的错误之一"，黑石总裁则称"AI供应远落后于需求"——多空双方都在等同一个开盘价。

芯片战的双向挤压：H200对华归零、BIS远程算力新规、USCC年度报告同周叠加，中方以2592 EFLOPS算力增速与"全国一张网"回应——供给侧脱钩与自主侧提速的赛跑，正在决定明年中国推理市场的成本曲线。
